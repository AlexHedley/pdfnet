# API reference

Select an application to browse its public types. Application APIs describe
their implementation; use the [library reference](api/PdfNet.yml) when
integrating PDF merging into another application.

# [Library](#tab/library)

The core library provides PDF merging and the shared desktop workflow.
[Browse the library API](api/PdfNet.yml).

# [Terminal](#tab/terminal)

The terminal app supports an interactive menu and command-line arguments.
[Browse the terminal API](api-tui/PdfNet.Tui.yml).

# [Folder merge](#tab/folder)

The file-based folder merge app has no separate public API. It calls
[PdfFolderMerger](api/PdfNet.PdfFolderMerger.yml) to combine top-level PDFs
in filename order.

# [WPF](#tab/wpf)

The WPF application uses the shared desktop selection and merge workflow.
[Browse the WPF API](api-wpf/PdfNet.Wpf.yml).

# [WinForms](#tab/winforms)

The Windows Forms application uses the shared desktop selection and merge
workflow. [Browse the WinForms API](api-winforms/PdfNet.WinForms.yml).

# [WinUI](#tab/winui)

The WinUI application uses the shared desktop selection and merge workflow.
[Browse the WinUI API](api-winui/PdfNet.WinUI.yml).

# [Browser](#tab/browser)

The Blazor WebAssembly application merges PDF streams locally in the browser.
[Browse the browser API](api-wasm/PdfNet.Wasm.yml).

***

For application controls and command examples, see the
[application guides](https://alexhedley.github.io/pdfnet/site/).
